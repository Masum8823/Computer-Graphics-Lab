# Draw Japan Flag

> OpenGL-এ basic shapes ব্যবহার করে Japan-এর national flag আঁকা।

---

# 1. Japan Flag কীভাবে বানাবো?

Japan-এর Flag খুব simple:

```text
White Rectangle
      +
Red Circle
      ↓
Japan Flag
```

দেখতে:

```text
┌──────────────────────────────┐
│                              │
│             ●                │
│                              │
└──────────────────────────────┘
```

এখানে:

```text
White → Background
Red   → Circle
```
