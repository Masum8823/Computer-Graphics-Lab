# Draw Bangladesh Flag

> OpenGL-এ basic shapes ব্যবহার করে বাংলাদেশের জাতীয় পতাকা আঁকা।

---

# 1. Bangladesh Flag কীভাবে বানাবো?

বাংলাদেশের Flag খুব সহজে ২টা shape দিয়ে বানানো যায়:

```text
Rectangle → Green Background

Circle → Red Circle
```

অর্থাৎ:

```text
Green Rectangle
       +
 Red Circle
       ↓
Bangladesh Flag
```

---

```text
┌──────────────────────────────┐

```
