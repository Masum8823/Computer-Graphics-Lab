# Scaling

> Scaling হলো কোনো object/shape-এর **size বড় বা ছোট করা**।

---

# 1. Scaling কী?

সহজ ভাষায়:

```text
Object
   ↓
Size Change
   ↓
Scaling
```

যেমন:

```text
Before:

  ┌───┐
  │   │
  └───┘


After Scaling:

  ┌───────┐
  │       │
  │       │
  └───────┘
```

Object-এর shape একই থাকবে, কিন্তু **size change হবে**।
