# Rotation

> Rotation হলো কোনো object/shape-কে একটি নির্দিষ্ট **angle** অনুযায়ী ঘুরানো।

---

# 1. Rotation কী?

সহজ ভাষায়:

```text
Object
   ↓
ঘুরবে
   ↓
New Angle
```

যেমন একটি square:

```text
Before:

┌────┐
│    │
└────┘


After Rotation:

  ╲
   ╲
    ╲
```

Shape-এর **size একই থাকবে**, শুধু angle পরিবর্তন হবে।
