# Draw a Polygon

> OpenGL-এ একাধিক Vertex ব্যবহার করে একটি closed shape তৈরি করার basic method।

---

# 1. Polygon কী?

Polygon মানে হলো **একাধিক straight line দিয়ে তৈরি একটি closed shape**।

যেমন:

```text
Triangle    → 3 sides
Rectangle   → 4 sides
Pentagon    → 5 sides
Hexagon     → 6 sides
```

সহজভাবে:

```text
3 Vertex → Triangle
4 Vertex → Quadrilateral
5 Vertex → Pentagon
6 Vertex → Hexagon
```
