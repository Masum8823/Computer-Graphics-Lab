# Translation

> Translation হলো কোনো object/shape-কে **এক জায়গা থেকে অন্য জায়গায় move করা**, কিন্তু shape-এর size বা angle পরিবর্তন হয় না।

---

# 1. Translation কী?

সহজ ভাষায়:

```text
Object
  ↓
Move
  ↓
New Position
```

যেমন:

```text
আগে                 পরে

  ■                    ■
                     →
```

Square-এর shape একই থাকবে, শুধু position change হবে।
