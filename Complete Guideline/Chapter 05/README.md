# Draw a Point

> OpenGL-এ একটি নির্দিষ্ট coordinate-এ একটি Point আঁকার basic method।

---

## 1. কী শিখবো?

এই program থেকে আমরা শিখবো:

* `GL_POINTS` কী
* `glPointSize()` কী
* `glVertex2f()` দিয়ে Point-এর position দেওয়া
* Point-এর size পরিবর্তন করা
* Coordinate দেখে Point-এর location বের করা
